01 / Fundamentos

¿Qué es programar y qué es un algoritmo?

Programar es darle órdenes a la computadora, paso a paso, para que resuelva un problema. Esa lista de pasos ordenados se llama algoritmo.

Un algoritmo es como una receta

Igual que la receta de las pupusas: si cambias el orden de los pasos, el resultado sale mal. La computadora hace exactamente lo que le dices, en el orden que le dices.

1 Agarrar la masa
2 Rellenar de queso
3 Aplastar y dar forma
4 Cocinar en el comal

Si pones «cocinar» antes de «rellenar», la pupusa sale cruda por dentro. ¡El orden importa!

Los lenguajes son los idiomas

A la computadora le hablamos en «lenguajes de programación». Cada uno sirve para cosas distintas, pero todos dan órdenes:

  • Python Fácil de leer, ideal para empezar.
  • C# Apps de escritorio y videojuegos (Unity).
  • PHP Páginas web y sistemas en el servidor.
  • Web HTML, CSS y JavaScript para el navegador.

Como el español y el inglés: distintas palabras, pero la idea de «dar órdenes» es la misma.

02 / Datos

Una variable es una cajita con nombre donde guardas un dato para usarlo después. El tipo de dato dice qué clase de información guarda esa cajita.

03 / Lógica

Condicionales y ciclos

Con los condicionales el programa toma decisiones; con los ciclos repite una tarea muchas veces sin que te canses de escribirla.

if — tomar decisiones

«Si pasa esto, haz aquello; si no, haz lo otro.» Igual que el cobrador del bus:

if pasaje >= 0.25:
  print("Suba, pues 🚌")
else:
  print("Le falta pisto 🙅")

for y while — repetir

Para no escribir lo mismo 100 veces. Por ejemplo, saludar a cada cliente de la fila:

# for: repite una cantidad conocida
for cliente in fila:
  print("¡Buenas! ¿Qué va a llevar?")

# while: repite mientras se cumpla algo
while hay_masa:
  hacer_pupusa()
Usa for cuando…

Sabes cuántas veces repetir. Ej: «cobra a los 8 clientes de la fila».

Usa while cuando…

Repites hasta que algo cambie. Ej: «sigue vendiendo mientras haya masa».

04 / Orden

Funciones y cómo encontrar errores

Una función es un bloque de código con nombre que hace una tarea y lo puedes reutilizar. Depurar es buscar y arreglar los errores («bugs»).

Funciones = tu máquina de pupusas

La construyes una vez y la usas mil veces. Le das ingredientes (parámetros) y te devuelve algo (return).

def precio_combo(cantidad):
  total = cantidad * 0.50
  return total

# La reutilizamos cuantas veces queramos
print(precio_combo(3)) # 1.5
print(precio_combo(8)) # 4.0

Depurar: caza de bugs 🐛

Todos los programadores se equivocan. Lo importante es saber buscar el error:

  • 1 Lee el mensaje de error. Dice la línea y el tipo de fallo.
  • 2 Revisa esa línea. ¿Falta un : o un paréntesis?
  • 3 Usa print(). Imprime variables para ver qué valor tienen.
  • 4 Prueba de a poco. Cambia una cosa a la vez.
